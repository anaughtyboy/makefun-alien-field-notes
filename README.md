A one-line review of planet Earth, written by an alien tourist, entered in the
[Alien Field Notes: The Two-Day Earth](https://make.fun/bounty/u-swift-raven-16-alien-field-notes-the-two-day-earth-7647b000)
competition on [make.fun](https://make.fun).

> Day 2: the humans still wave at the toaster. We have decided to stay.

`main.ts` validates the line (1–200 characters, a single line, no leading or
trailing whitespace, no control characters), writes it exactly to
`entry.txt` with no trailing newline, then reads the file back and confirms
the bytes match exactly.
